# Overview

## Business
**Nafi Lock Industries** — a lock manufacturer with three brands sold in parallel
(not tiered by price/quality — each is a distinct brand identity, all producing
classic locks):

- **S-Nafi**
- **Greek**
- **Raksham**

## Purpose of the website
A catalog/showcase site so visitors (dealers, distributors, and general
customers) can browse the full product range across all three brands, learn
about the company, and submit an inquiry.

## Reference sites (style inspiration)
- **atomlocks.com** — same industry (hardware/locks); positions locks as
  premium/luxury hardware rather than plain commodity items; has categories
  (Pull Handle, Mortice Handle, Glass Knobs), e-commerce-style presentation,
  and a dealer-facing "Free Display" offer.
- **velisqa.com** — different industry (jewellery) but referenced for its
  premium, dark, product-forward visual feel.

The site should borrow the "premium hardware showroom" feeling from these,
translated into Nafi's own brass/steel visual language rather than copying
either site directly.

## Not in scope (for now)
- No e-commerce/cart/checkout — this is a catalog + inquiry site, not a store.
- No public user accounts — only an admin panel for managing content.
